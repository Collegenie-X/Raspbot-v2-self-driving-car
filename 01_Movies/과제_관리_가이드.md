## 🎓 과제 핵심 개념

### 1 Frame = 1장의 이미지 처리

```
카메라 이미지 1장
    ↓
TODO 1: 차선 인식 → 기어모터 제어
TODO 2: 신호등 인식 → 기어모터/부저 제어
TODO 3: 표지판 인식 → 기어모터/부저 제어
TODO 4: 주차공간 인식 → 기어모터 주차 제어
TODO 5: 장애물 인식 → 기어모터/부저 제어
    ↓
다음 Frame (20회 반복)
```

**핵심**: 
- 각 TODO에서 **random → 조건문 → print** 
- 복잡한 계산 없이 **간단한 if문**만 사용

## 🎯 채점 예시

### 만점 예시 (10점)

```python
def lane_detection_and_control():
    print("\n[TODO 1] 차선 인식 & 제어")
    
    # random 사용 ✅
    lane_positions = ["left", "center", "right", "fail"]
    detected = random.choice(lane_positions)
    print(f"  📸 인식 결과: {detected}")
    
    # 조건문 사용 ✅
    if detected == "left":
        # 인식 후 즉시 제어 출력 ✅
        print(f"  ⚙️ 기어모터: 우회전 전진")
    elif detected == "center":
        print(f"  ⚙️ 기어모터: 직진 전진")
    elif detected == "right":
        print(f"  ⚙️ 기어모터: 좌회전 전진")
    else:
        print(f"  ⚠️ 인식 실패")
        print(f"  ⚙️ 기어모터: 감속")
```

### 감점 예시 (5점)

def lane_detection():

    # 제어 명령 없음 (-2점)

## 🚨 자주 발생하는 오류

### 오류 1: 제어 시스템 따로 분리

**학생 코드**:
```python
def lane_detection():
    # 인식만 하고 제어 없음
    detected = random.choice(["left", "center", "right"])
    print(f"차선: {detected}")
    return detected  # 제어를 나중에 하려고 return

def control_motor():
    # 제어를 따로 함수로 분리
    print("모터 제어")
```

**피드백**:
> 각 TODO에서 인식 후 **즉시** 제어 명령을 출력해야 합니다.  
> 제어 시스템을 따로 분리하지 마세요.

### 오류 2: random 미사용

**학생 코드**:
```python
detected = "center"  # 고정값
```

**피드백**:
> random 모듈을 사용하여 다양한 상황을 시뮬레이션해야 합니다.  
> 예시: `detected = random.choice(["left", "center", "right", "fail"])`

### 오류 3: 조건문 없이 단순 출력

**학생 코드**:
```python
print("기어모터: 전진")  # 조건문 없음
```

**피드백**:
> random으로 생성한 값에 따라 조건문(if/elif/else)으로 제어를 결정해야 합니다.

### Q3: 주차는 어떻게 구현하나요?

**답변**: 간단하게! 위치와 크기만 확인하세요.
```python
# 1. 위치 확인
parking_positions = ["left", "center", "right", "fail"]
detected_position = random.choice(parking_positions)

if detected_position == "center":
    # 2. 크기(거리) 확인
    parking_sizes = ["big", "small"]
    detected_size = random.choice(parking_sizes)
    
    if detected_size == "big":
        print("주차 가능! 후진 주차")
    else:
        print("더 접근 필요")
```

**핵심**: 복잡한 계산 없이 random + 조건문만!

### Q4: 1 Frame에서 모든 TODO를 처리한다는 게 뭔가요?

**답변**:
카메라가 촬영한 1장의 이미지에서:
1. TODO 1 실행 (차선 인식 & 제어)
2. TODO 2 실행 (신호등 인식 & 제어)
3. TODO 3 실행 (표지판 인식 & 제어)
4. TODO 4 실행 (주차 인식 & 제어)
5. TODO 5 실행 (장애물 인식 & 제어)

이것이 1 Frame 처리입니다. 20 Frames = 위 과정 20회 반복

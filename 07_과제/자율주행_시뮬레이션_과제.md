## 🎯 미션 요구사항

### 전체 흐름
```
시작 → 20회 주행 반복 → 미션 완료 or 충돌 2회로 종료
```

### 단계별 구현 내용

#### **1단계: 미션 시작**
- 총 20번의 주행 반복
- 매 주행마다 방향과 표지판을 랜덤으로 결정

---

#### **2단계: 주행 방향 결정**

**방향 종류**: `"up"`, `"left"`, `"right"`, `"random"`

| 방향 | 의미 | 출력 내용 |
|------|------|-----------|
| `up` | 직진 | "차량이 직진합니다." |
| `left` | 좌회전 | "차량이 좌회전합니다." |
| `right` | 우회전 | "차량이 우회전합니다." |
| `random` | 판단 어려움 | "서보 모터로 방향 탐색 중..." → 이후 좌/우/직진 중 선택 |

**구현 포인트**:
- `random` 방향일 때는 서보 모터를 활용한다는 시뮬레이션 후, 최종적으로 좌/우/직진 중 하나 선택

---

#### **3단계: 표지판 인식**

**표지판 종류**: `"stop"`, `"danger"`, `"o_sign"`, `"no_sign"`

| 표지판 | 의미 | 세부 동작 |
|--------|------|-----------|
| `stop` | 정지 표지판 | ① 표지판 인식 출력<br>② 기어모터 정지<br>③ 부저 3회 울림 (삐- 삐- 삐-)<br>④ 주행 종료 |
| `danger` | 위험 표지판 | ① 표지판 인식 출력<br>② 기어모터 정지<br>③ 부저 도미솔 음계 재생<br>④ 주행 종료 |
| `o_sign` | 주차 공간 | ① O 표지판 인식 출력<br>② rect(x, y, width, height) 좌표 생성<br>③ O 표지판 위치 추적 (좌/중앙/우)<br>④ 자율 주차 동작 실행<br>⑤ 주차 완료 메시지 |
| `no_sign` | 표지판 없음 | ① "차량이 계속 주행합니다" 출력<br>② 정상 주행 계속 |

---

**🔍 각 표지판별 구현 가이드**

**1) `stop` 표지판 처리**
```
1. 표지판 인식 → "정지 표지판 인식!"
2. 기어모터 정지 → "기어모터: 정지"
3. 부저 3회 → "부저: 삐- 삐- 삐- (3회)"
4. 주행 종료 → 다음 주행으로 이동
```

**2) `danger` 표지판 처리**
```
1. 표지판 인식 → "위험 표지판 인식!"
2. 기어모터 정지 → "기어모터: 긴급 정지"
3. 부저 음계 → "부저: 도-미-솔 음계 재생"
4. 주행 종료 → 다음 주행으로 이동
```

**3) `o_sign` 주차 공간 처리 (중요!)**
```
1. O 표지판 인식 → "주차 공간(O) 인식!"
2. rect 좌표 생성 → rect(x, y, width, height) 랜덤 생성
3. 위치 판단:
   x,y에 따른 위치 판단 
4. 크기 판단 (width * height 기준):
   크기에 따른 거리 측정 
```

**4) `no_sign` 처리**
```
1. 표지판 없음 → "표지판 없음, 정상 주행"
2. 계속 주행 → "차량이 계속 주행합니다"
```

---

**구현 포인트**:
- `o_sign`의 **rect 좌표는 랜덤 생성**: `x(0~640)`, `y(0~480)`, `width(50~150)`, `height(50~150)`
- `o_sign`의 **위치 추적**: x 좌표를 기준으로 좌/중앙/우 판단 (화면을 3등분)
- `o_sign`의 **거리 판단**: width 크기로 가까움/멀음 판단 (width가 크면 가까운 것)
- `stop`이나 `danger`는 **주행을 즉시 종료**하고 다음 주행(루프)으로 이동

---

#### **4단계: 충돌 여부 체크**

- 매 주행마다 **10% 확률**로 충돌 발생 (`random.random() < 0.1`)
- 충돌 발생 시: 충돌 횟수 +1, "충돌 한 번이 실행했습니다." 출력
- **충돌 2회 이상**: "충돌이 2번 발생했습니다! 미션 종료!" → 프로그램 종료

---

#### **5단계: 주행 상태 출력**

매 주행마다 현재 상태를 출력합니다.

**출력 예시**:
```
현재 주행 방향: up, 표지판: stop, 현재 충돌 횟수: 1
```

---

#### **6단계: 주행 반복**

- 위 과정(2~5단계)을 **20번 반복**
- 충돌 2회 발생 시 즉시 종료

---

#### **7단계: 미션 종료**

**정상 완료 조건**: 20번 주행 완료 + 충돌 2회 미만  
**출력**: "미션 완료! 목적지에 도달했습니다."

**비정상 종료**: 충돌 2회 이상  
**출력**: "충돌이 2번 발생했습니다! 미션 종료!"

## 💻 예시 코드 구조

```python
import random

def determine_direction():
    """주행 방향 결정"""
    directions = ["up_line", "left_line", "right_line", "random"]
    direction = random.choice(directions)
    
    
    if direction = "up_line" : 
        print("자동차 직진 방향 " )

        return "up" 

    # left_line  일때
    # right_line 일때 
    
    elif direction == "random":  ### 막다른 길 처리 
        print("서보 모터로 방향 탐색 중...")
        # 서보 모터 시뮬레이션 후 최종 방향 결정
        #        :       
        #        :
        return "right" 
    
    
    

def detect_sign():
    """표지판 인식 및 처리"""
    signs = ["stop", "danger", "o_sign", "no_sign"]
    sign = random.choice(signs)
    
    if sign == "stop":
        # 1. 표지판 인식
        # 2. 기어모터 정지
        # 3. 부저 3회
        
    elif sign == "danger":
        # 1. 표지판 인식
        # 2. 기어모터 긴급 정지
        # 3. 부저 도미솔 음계
        
    elif sign == "o_sign":
        # 1. O 표지판 인식
        # 2. rect 좌표 생성 (랜덤)
        x = random.randint(0, 640)
        y = random.randint(0, 480)
        width = random.randint(50, 200)
        height = random.randint(50, 200)
        print(f"📍 rect 좌표: ({x}, {y}, {width}, {height})")
        
        # 3. x,y에 따른 위치 추적 (x 좌표 기준)
        # 4. width * height에 따른 거리 판단 (width 기준)
        # 5. 주차 알고리즘으로 주차 
            
    else:  # no_sign
        print("✅ 표지판 없음, 정상 주행")
        print("🚗 차량이 계속 주행합니다")
    
    return sign

def check_collision():
    """충돌 체크 (10% 확률)"""
    if random.random() < 0.1:
        print("충돌 한 번이 실행했습니다.")
        return True
    return False

def main():
    """메인 자율주행 시뮬레이션"""
    collision_count = 0
    
    for i in range(1, 21):
        print(f"\n{'='*50}")
        print(f"🚗 주행 {i}/20")
        print(f"{'='*50}")
        
        # 1단계 : 방향 결정
        direction = determine_direction()
        
        # 2단계: 표지판 인식
        sign = detect_sign()
        
        # 3단계: 충돌 체크
        if check_collision():
            # 충돌 횟수 1 증가
            # 만약 충돌이 2회 이상이면 "충돌이 2번 발생했습니다! 미션 종료!" 출력 후 종료
        
        # 4단계 : 상태 출력
        print(f"현재 주행 방향: {direction}, 표지판: {sign}, 현재 충돌 횟수: {collision_count}")
    
    print("\n🎉 미션 완료! 목적지에 도달했습니다.")

if __name__ == "__main__":
    main()
```

## 💡 구현 팁

1. **함수 분리**: 각 기능(방향, 표지판, 충돌)을 별도 함수로 작성
2. **명확한 변수명**: `collision_count`, `current_direction` 등 의미 있는 이름 사용
3. **주석 작성**: 각 단계별로 한글 주석 추가
4. **Early Return**: 충돌 2회 시 즉시 종료
5. **랜덤 활용**: `random.choice()`, `random.random()`, `random.randint()` 적절히 사용

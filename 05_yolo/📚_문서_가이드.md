## 🚀 빠른 참조

### Raspberry Pi 5 최적 설정

```python
# 모델
model = "yolo11n.onnx"  # Nano + ONNX

# 훈련 설정
epochs = 150
batch = 32
imgsz = 416  # 최적 균형점
optimizer = "AdamW"

# 추론 설정
conf_threshold = 0.35
iou_threshold = 0.5

# 기대 성능
FPS = 25-30  # 실시간 충분
mAP50 = 0.75-0.85  # 높은 정확도
```

### 필수 명령어

```bash
# 1. 라벨 검증
python scripts/labeling/label_quality_checker.py \
  --images dataset/images --labels dataset/labels

# 2. 데이터셋 분할
python scripts/dataset/dataset_splitter.py \
  --images raw/images --labels raw/labels --output yolo_dataset

# 3. 설정 파일 생성
python scripts/dataset/create_data_yaml.py \
  --dataset yolo_dataset --classes class1 class2 class3

# 4. Pi 5 최적화 훈련
python scripts/training/train_yolo11_pi5_optimized.py \
  --data yolo_dataset/data.yaml --epochs 150

# 5. 테스트
python scripts/inference/test_inference.py \
  --weights best.onnx --webcam
```

# 자율주행 미션 요구사항 분석 (Raspbot v2)

## 📋 1. 개요
본 문서는 자율주행 챌린지 미션 영상을 기반으로, **Raspbot v2 플랫폼**에서 동일한 기능을 구현하기 위한 요구사항을 분석하고 정리한 문서입니다.

### 1.1 미션 목표
- 🚦 신호등 인식 및 출발 제어
- 🛣️ 차선 유지 주행 (직선 + 곡선)
- 🚧 장애물 감지 및 회피
- 🛑 교통 표지판 인식 및 대응 (Haar Cascade)
- 🚗 자동차 객체 회피
- 🅿️ 자동 주차 (주차장 0 표시 인식)

### 1.2 특수 환경 조건 ⚠️
본 프로젝트는 다음과 같은 특수한 환경에서 동작합니다:

| 환경 요소 | 상세 설명 | 대응 전략 |
|:---|:---|:---|
| **도로 폭** | 자동차 3대 정도 지나가는 폭 | 단일 차선 인식 알고리즘 적용 |
| **차선 가시성** | 카메라에 양쪽 차선이 잡히지 않음 | 한쪽 차선만으로 좌/우/직진 판단 |
| **도로 배경색** | 검정색 (아스팔트) | 반사광 노이즈 필터링 필수 |
| **빛 반사** | 조명에 의한 반사로 오검출 발생 | 적응형 임계값 + 모폴로지 연산 |
| **객체 인식** | Haar Cascade 모델 사용 | 표지판, 신호등, 자동차, 주차표시 |

## 🎯 2. 전체 미션 플로우차트

```mermaid
flowchart TD
    A[시스템 초기화] --> B[신호등 대기]
    B --> C{신호등 색상 판별}
    C -->|빨간불| B
    C -->|초록불| D[차선 주행 시작]
    
    D --> E{장애물 감지?}
    E -->|Yes| F[일시 정지]
    F --> G{회피 가능?}
    G -->|Yes| H[차선 변경 회피]
    G -->|No| F
    H --> D
    
    E -->|No| I{표지판 인식?}
    I -->|정지| J[3초 정지]
    I -->|감속| K[속도 감소]
    I -->|주차| L[주차 모드 전환]
    I -->|없음| D
    
    J --> D
    K --> D
    L --> M[주차 공간 탐색]
    M --> N[후진 주차 실행]
    N --> O[미션 완료]
```

### 5.2 차선 유지 주행 (핵심 미션) - 단일 차선 인식 방식

#### 🎯 단일 차선 기반 주행 전략
도로 폭이 좁아 양쪽 차선이 카메라에 잡히지 않으므로, **한쪽 차선만 인식**하여 주행합니다.

```mermaid
flowchart LR
    A[단일 차선 검출] --> B{차선 위치 판단}
    B -->|화면 왼쪽| C[우회전 필요]
    B -->|화면 중앙| D[직진]
    B -->|화면 오른쪽| E[좌회전 필요]
    C --> F[서보 각도 +15~30도]
    D --> G[서보 각도 0도]
    E --> H[서보 각도 -15~-30도]
```

#### 전체 알고리즘 플로우
```mermaid
flowchart TD
    A[카메라 프레임<br/>640x480] --> B[1단계: 노이즈 제거]
    
    B --> C[검정색 배경 필터링]
    C --> D[반사광 노이즈 제거]
    D --> E[ROI 설정<br/>하단 50%]
    
    E --> F[2단계: 차선 검출]
    F --> G[HSV 변환]
    G --> H[노란색/흰색 마스크]
    H --> I[모폴로지 연산]
    I --> J[Canny Edge]
    J --> K[Hough Line 검출]
    
    K --> L{검출된 차선 개수}
    L -->|0개| M[마지막 조향각 유지<br/>또는 직진]
    L -->|1개| N[3단계: 위치 분석]
    L -->|2개 이상| O[가장 명확한 1개 선택]
    
    O --> N
    N --> P[차선 X좌표 추출]
    P --> Q{X좌표 위치 판단}
    
    Q -->|0~213| R[차선이 왼쪽<br/>우회전 필요]
    Q -->|214~426| S[차선이 중앙<br/>직진]
    Q -->|427~640| T[차선이 오른쪽<br/>좌회전 필요]
    
    R --> U[PID 제어]
    S --> U
    T --> U
    U --> V[서보 모터 출력]
```

#### PID 제어 로직
```mermaid
flowchart LR
    A[차선 중심 X] --> B[오차 = 중심 - 화면중심]
    B --> C[P항: Kp * 오차]
    B --> D[I항: Ki * 오차 누적]
    B --> E[D항: Kd * 오차 변화량]
    C --> F[조향각 = P + I + D]
    D --> F
    E --> F
    F --> G[서보 각도 변환<br/>45도 ~ 135도]
```

#### 튜닝 파라미터
| 파라미터 | 초기값 | 범위 | 설명 |
|:---|:---:|:---:|:---|
| Kp (비례) | 0.5 | 0.3 ~ 1.0 | 즉각 반응 강도 |
| Ki (적분) | 0.01 | 0.0 ~ 0.05 | 누적 오차 보정 |
| Kd (미분) | 0.3 | 0.1 ~ 0.5 | 진동 억제 |
| 기본 속도 | 30% | 20 ~ 50% | DC 모터 PWM |

### 5.2.1 검정색 배경 필터링 알고리즘 (1단계 전처리)

검정색 아스팔트 도로에서 빛 반사로 인한 오검출을 방지하기 위한 필터링 알고리즘입니다.

```mermaid
flowchart TD
    A[입력 프레임<br/>BGR] --> B[HSV 변환]
    
    B --> C[명도V 채널 추출]
    C --> D{V값 분석}
    
    D --> E[히스토그램 계산]
    E --> F{평균 명도 < 80?}
    
    F -->|Yes 어두운 환경| G[적응형 임계값 사용<br/>ADAPTIVE_THRESH]
    F -->|No 밝은 환경| H[고정 임계값 사용<br/>V > 100]
    
    G --> I[검정색 영역 마스크 생성]
    H --> I
    
    I --> J[검정색 영역 제거<br/>inRange lower V=0-50]
    J --> K[유효 영역만 추출]
    K --> L[다음 단계로 전달]
    
    style I fill:#ff6b6b
    style J fill:#ff6b6b
```

#### 파라미터 설정
| 구분 | HSV 범위 | 설명 |
|:---|:---|:---|
| **검정색 배경** | H: 모든값, S: 0-50, V: 0-50 | 제거 대상 |
| **차선 (흰색)** | H: 모든값, S: 0-50, V: 200-255 | 검출 대상 |
| **차선 (노란색)** | H: 15-35, S: 100-255, V: 100-255 | 검출 대상 |

### 5.2.2 빛 반사 노이즈 제거 알고리즘 (2단계 전처리)

조명이나 태양광 반사로 인한 과도하게 밝은 영역을 필터링합니다.

```mermaid
flowchart TD
    A[전처리된 프레임] --> B[그레이스케일 변환]
    
    B --> C[밝기 임계값 적용]
    C --> D{픽셀 밝기 > 240?}
    
    D -->|Yes| E[과포화 영역 감지]
    D -->|No| F[정상 영역]
    
    E --> G[연결된 영역 분석<br/>connectedComponents]
    G --> H{영역 크기 < 100px?}
    
    H -->|Yes 노이즈| I[해당 영역 제거]
    H -->|No 유효| J[유지]
    
    I --> K[모폴로지 Closing<br/>작은 구멍 메우기]
    J --> K
    F --> K
    
    K --> L[가우시안 블러<br/>5x5 커널]
    L --> M[노이즈 제거 완료]
    
    style E fill:#ffe66d
    style I fill:#ff6b6b
```

### 5.3 장애물 감지 및 회피

#### 센서 융합 로직
```mermaid
flowchart TD
```

#### 전체 PID 계산 플로우
```mermaid
flowchart TD
```

#### PID 각 항의 역할 도식
```mermaid
flowchart LR
    subgraph "P항 - 비례"
        A1[현재 오차] --> A2[즉각 반응]
        A2 --> A3[Kp × error]
    end
    
    subgraph "I항 - 적분"
        B1[누적 오차] --> B2[꾸준한 보정]
        B2 --> B3[Ki × Σerror]
    end
    
    subgraph "D항 - 미분"
        C1[오차 변화율] --> C2[진동 억제]
        C2 --> C3[Kd × Δerror]
    end
    
    A3 --> D[합산]
    B3 --> D
    C3 --> D
    D --> E[최종 조향각]
```

#### PID 동작 시뮬레이션
```
[차선이 왼쪽에 위치 - 우회전 필요]

시간 | 차선X | 목표X | 오차  | P항  | I항 | D항  | 조향각
-----|------|-------|-------|------|-----|------|-------
 0ms |  100 | 106.5 |  -6.5 | -3.3 | 0.0 |  0.0 |  -3.3°
33ms |  103 | 106.5 |  -3.5 | -1.8 | -0.1| +0.9 |  -1.0°
66ms |  105 | 106.5 |  -1.5 | -0.8 | -0.2| +0.6 |  -0.4°
99ms |  107 | 106.5 |  +0.5 | +0.3 | -0.2| +0.6 |  +0.7°
                                            ↑
                                         수렴!

[설명]
- P항: 오차에 비례하여 즉각 반응
- I항: 누적 오차를 점진적으로 제거
- D항: 급격한 변화를 완화하여 안정화
```

#### 수식
\[
\text{조향각}(t) = K_p \cdot e(t) + K_i \cdot \int_0^t e(\tau) d\tau + K_d \cdot \frac{de(t)}{dt}
\]

여기서:
- \( e(t) \) = 차선 X좌표 - 목표 X좌표
- \( K_p \) = 비례 게인 (0.3 ~ 1.0)
- \( K_i \) = 적분 게인 (0.0 ~ 0.05)
- \( K_d \) = 미분 게인 (0.1 ~ 0.5)

#### 파라미터 튜닝 가이드
| 현상 | 원인 | 조치 | 우선순위 |
|:---|:---|:---|:---:|
| 차선 이탈 반복 | Kp 너무 작음 | Kp 증가 (0.1씩) | ⭐⭐⭐⭐⭐ |
| 좌우 흔들림 심함 (Oscillation) | Kp 너무 큼 | Kp 감소 또는 Kd 증가 | ⭐⭐⭐⭐⭐ |
| 곡선에서 이탈 | Ki 너무 작음 | Ki 증가 (0.01씩) | ⭐⭐⭐⭐ |
| 과도한 조향 (Overshoot) | Ki 너무 큼 | Ki 감소 | ⭐⭐⭐⭐ |
| 진동 발생 | Kd 부족 | Kd 증가 (0.1씩) | ⭐⭐⭐ |
| 반응 느림 | 모든 게인 작음 | Kp 먼저 증가 | ⭐⭐⭐⭐ |
| 차선 중앙 정렬 안됨 | Ki = 0 | Ki 추가 (0.01) | ⭐⭐⭐ |

#### 튜닝 순서 (추천)
```mermaid
flowchart LR
    A[1단계<br/>Ki=0, Kd=0<br/>Kp만 조정] --> B[2단계<br/>Kd 추가<br/>진동 억제]
    B --> C[3단계<br/>Ki 추가<br/>정밀 정렬]
    C --> D[4단계<br/>미세 조정<br/>전체 밸런스]
```

```
│                  ⚖️ 3단계: 우선순위 판단 (2ms)               │
│  P1: 긴급정지 > P2: 신호등 > P3: 표지판 > P4: 차선추종       │
└────────────────────┬─────────────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────────────┐
│                  🎮 4단계: 제어 계산 (3ms)                    │
│  • PID 계산 (P + I + D)                                       │
│  • 조향각 결정 (-45° ~ +45°)                                  │
│  • 속도 결정 (20% ~ 50% PWM)                                  │
└────────────────────┬─────────────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────────────────┐
│                  ⚡ 5단계: 모터 출력 (3ms)                    │
│  • 서보 모터 (45° ~ 135°)                                     │
│  • DC 모터 (0% ~ 100% PWM)                                    │
└──────────────────────────────────────────────────────────────┘

총 처리 시간: ~28ms (30 FPS 달성 가능)
```

### 14.3 주요 알고리즘 비교표
| 기능 | 기존 방식 | 본 프로젝트 방식 | 장점 |
|:---|:---|:---|:---|
| **차선 검출** | 양쪽 차선 인식 | **단일 차선** 3구역 분류 | 좁은 도로 대응 |
| **배경 처리** | 단순 임계값 | **검정색 필터링** + 반사광 제거 | 노이즈 감소 |
| **객체 인식** | 딥러닝 (YOLO) | **Haar Cascade** 멀티 모델 | 저사양 최적화 |
| **센서 융합** | 카메라만 | **초음파 + 카메라** | 신뢰도 향상 |
| **우선순위** | 없음 | **4단계 우선순위** 시스템 | 안전성 증가 |
| **에러 처리** | 기본 | **4레벨 복구** 전략 | 안정성 향상 |

## 1. 기술 개요

### 1.1 Haar Cascade (2001년)

```
┌─────────────────────────────────────────────────┐
│ Haar Cascade                                    │
├─────────────────────────────────────────────────┤
│ 발표: 2001년 (Paul Viola, Michael Jones)        │
│ 방식: 머신러닝 (AdaBoost)                        │
│ 특징: Haar-like features                        │
│ 검출: 슬라이딩 윈도우                            │
│ 속도: 매우 빠름 (CPU 최적화)                     │
│ 정확도: 제한적                                   │
└─────────────────────────────────────────────────┘
```

**작동 원리**:
```
1. Haar-like Feature 추출
   ├─ 흑백 패턴 검색
   ├─ 사각형 영역 명암 차이 계산
   └─ 단순한 특징 (눈, 코, 입 등)

2. AdaBoost 학습
   ├─ 약한 분류기 조합
   ├─ Cascade 구조 (단계별 검출)
   └─ 빠른 거부 (false 빠르게 제거)

3. 슬라이딩 윈도우
   ├─ 전체 이미지 스캔
   ├─ 다양한 크기로 반복
   └─ 모든 위치 검사

문제점:
❌ 단일 클래스만 (얼굴, 눈 등)
❌ 각도 변화에 취약
❌ 조명 변화에 취약
❌ False Positive 매우 많음
❌ 훈련 매우 어렵고 오래 걸림 (수일-수주)
```

### 1.2 YOLO11n (2024년)

```
┌─────────────────────────────────────────────────┐
│ YOLO11n (You Only Look Once v11 nano)           │
├─────────────────────────────────────────────────┤
│ 발표: 2024년 (Ultralytics)                      │
│ 방식: 딥러닝 (CNN)                               │
│ 특징: End-to-End Learning                       │
│ 검출: Single-Shot Detection                     │
│ 속도: 빠름 (Pi 5: 25-30 FPS)                    │
│ 정확도: 매우 높음 (mAP50 0.75-0.85)             │
└─────────────────────────────────────────────────┘
```

**작동 원리**:
```
1. Backbone Network
   ├─ CSPDarknet (특징 추출)
   ├─ 다층 Convolution
   └─ 계층적 특징 학습

2. Neck (FPN + PAN)
   ├─ 다중 스케일 특징 융합
   ├─ 작은 객체~큰 객체 모두 검출
   └─ 정보 흐름 최적화

3. Head (예측)
   ├─ Anchor-free 검출
   ├─ 바운딩 박스 + 클래스 + 신뢰도
   └─ NMS (중복 제거)

장점:
✅ 다중 클래스 동시 검출 (무제한)
✅ 각도 변화 강인함
✅ 조명 변화 강인함
✅ 부분 가림 대응
✅ False Positive 적음
✅ 훈련 쉽고 빠름 (수 시간)
```

## 2. 성능 비교

### 2.1 속도 비교 (Raspberry Pi 5)

| 항목 | Haar Cascade | YOLO11n (PT) | YOLO11n (ONNX) |
|------|--------------|--------------|----------------|
| **320x320** | 40-45 FPS | 30-35 FPS | 40-45 FPS |
| **416x416** | 35-40 FPS | 22-25 FPS | 28-32 FPS |
| **640x480** | 30-35 FPS | 12-15 FPS | 16-20 FPS |
| **640x640** | 25-30 FPS | 6-8 FPS | 8-10 FPS |

**분석**:
```
✅ 작은 크기 (320x320):
   - Haar: 약간 빠름 (+10%)
   - YOLO ONNX: 거의 동일
   
✅ 중간 크기 (416x416):
   - Haar: 약간 빠름 (+20%)
   - YOLO ONNX: 충분히 빠름 (25+ FPS)
   
✅ 큰 크기 (640x640):
   - Haar: 훨씬 빠름 (+2배)
   - YOLO: 느림 (하지만 정확도 압도적)
   
결론: 416x416 크기에서 YOLO는 속도도 충분하면서
      정확도가 압도적으로 우수
```

## 4. 개발 편의성

### 4.1 훈련 과정 비교

#### Haar Cascade 훈련

```bash
난이도: ⭐⭐⭐⭐⭐ (매우 어려움)
소요 시간: 2-4주

1. 데이터 준비
   - 수천 장의 Positive 이미지
   - 수만 장의 Negative 이미지
   - 매우 엄격한 형식 요구
   
2. 특징 설정
   - XML 파일 수동 작성
   - 복잡한 파라미터 튜닝
   - 전문 지식 필요
   
3. 훈련 실행
   - opencv_traincascade 명령어
   - 수일-수주 소요
   - 중간에 실패하면 처음부터 다시
   
4. 결과
   - .xml 파일 1개
   - 단일 클래스만
   - 추가 클래스는 처음부터 다시

예시 (얼굴 검출기 훈련):
# 1. 데이터 준비
./opencv_createsamples -info positives.txt -vec samples.vec -num 5000

# 2. 훈련 (7-14일 소요)
./opencv_traincascade \
  -data cascade \
  -vec samples.vec \
  -bg negatives.txt \
  -numPos 4500 \
  -numNeg 10000 \
  -numStages 20 \
  -precalcValBufSize 1024 \
  -precalcIdxBufSize 1024 \
  -featureType HAAR \
  -minHitRate 0.999 \
  -maxFalseAlarmRate 0.5

문제점:
❌ 매우 복잡한 과정
❌ 오래 걸림 (수일-수주)
❌ 실패 시 처음부터
❌ 파라미터 튜닝 어려움
❌ 전문 지식 필요
```

### 4.2 코드 복잡도 비교

#### Haar Cascade 코드

```python
# 복잡도: 중간
# 단점: 단일 클래스만, 수동 튜닝 많음

import cv2

# 1. Cascade 로드
face_cascade = cv2.CascadeClassifier('haarcascade_frontalface_default.xml')
eye_cascade = cv2.CascadeClassifier('haarcascade_eye.xml')

# 2. 이미지 로드 및 전처리
img = cv2.imread('image.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # 필수: 흑백 변환

# 3. 검출 (수동 파라미터 튜닝 필요)
faces = face_cascade.detectMultiScale(
    gray,
    scaleFactor=1.1,      # 이미지 피라미드 스케일
    minNeighbors=5,       # 최소 이웃 수
    minSize=(30, 30),     # 최소 크기
    flags=cv2.CASCADE_SCALE_IMAGE
)

# 4. 눈 검출 (각 얼굴에 대해 반복)
for (x, y, w, h) in faces:
    roi_gray = gray[y:y+h, x:x+w]
    eyes = eye_cascade.detectMultiScale(roi_gray)
    
    for (ex, ey, ew, eh) in eyes:
        cv2.rectangle(img, (x+ex, y+ey), (x+ex+ew, y+ey+eh), (0, 255, 0), 2)

# 문제점:
# - 클래스마다 별도 Cascade 필요
# - 흑백 변환 필수
# - 파라미터 수동 튜닝
# - 다중 클래스 어려움
```

#### YOLO11n 코드

```python
# 복잡도: 매우 낮음
# 장점: 다중 클래스, 자동화

from ultralytics import YOLO

# 1. 모델 로드 (한 줄)
model = YOLO('best.onnx')

# 2. 검출 (한 줄)
results = model.predict('image.jpg', conf=0.35)

# 3. 결과 사용
for result in results:
    boxes = result.boxes
    for box in boxes:
        cls = int(box.cls[0])
        conf = float(box.conf[0])
        x1, y1, x2, y2 = box.xyxy[0]
        
        print(f"{result.names[cls]}: {conf:.2f}")

# 장점:
# - 모든 클래스 동시 검출
# - 자동 전처리
# - 최소 코드
# - 간단한 사용
```

## 평가 개요

### 기본 정보
- **최저 점수**: 70점
- **최고 점수**: 100점
- **기본 출발 점수**: 70점

### 평가 철학
이 평가 시스템은 학생들의 **구현 능력**과 **코드 품질**을 종합적으로 평가합니다. 단순히 기능 구현 여부만이 아니라, 코드의 구조화, 가독성, 고급 프로그래밍 기법 활용 등을 종합적으로 고려합니다.

## 세부 평가 항목

### 1. rect 랜덤 좌표 생성 (총 8점)

#### 평가 목적
표지판(O)의 위치와 크기를 랜덤하게 생성하는 능력을 평가합니다. 이는 시뮬레이션의 다양성을 확보하는 핵심 기능입니다.

#### 세부 항목

**1-1. X좌표 랜덤생성 (2점)**
- **평가 기준**: 
  - `random` 모듈 사용 확인
  - x, x_pos, rect_x, pos_x, sign_x 등의 변수명 사용
  - 0~640 범위 또는 WIDTH 상수 사용
- **통과 조건**:
  ```python
  # 예시 1: 범위 지정
  x = random.randint(0, 640)
  
  # 예시 2: 상수 사용
  x = random.randint(X_MIN, X_MAX)
  ```
- **점수 부여**: 조건 충족 시 2점, 미충족 시 0점

**1-2. Y좌표 랜덤생성 (2점)**
- **평가 기준**: 
  - `random` 모듈 사용 확인
  - y, y_pos, rect_y 등의 변수명 사용
  - 0~480 범위 또는 HEIGHT 상수 사용
- **통과 조건**: X좌표와 동일한 패턴
- **점수 부여**: 조건 충족 시 2점

**1-3. 너비(width) 랜덤생성 (2점)**
- **평가 기준**:
  - `random` 모듈 사용
  - w, width, rect_w 등의 변수명
  - 50~150 범위 권장
- **점수 부여**: 조건 충족 시 2점

**1-4. 높이(height) 랜덤생성 (2점)**
- **평가 기준**: width와 동일한 패턴
- **점수 부여**: 조건 충족 시 2점

#### 왜 이렇게 평가하는가?
rect 좌표는 자율주행 시뮬레이션에서 표지판의 위치와 크기를 결정하는 핵심 요소입니다. 각 좌표를 독립적으로 평가하여 학생이 **2차원 좌표계**와 **객체 크기 개념**을 정확히 이해하고 있는지 확인합니다.

### 2. 위치 추적 로직 (총 3점)

#### 평가 목적
표지판의 X 좌표를 기반으로 화면을 좌/중/우로 구분하여 차량의 조향 방향을 결정하는 로직을 평가합니다.

#### 세부 항목

**2-1. 좌측 영역 판별 (1점)**
- **평가 기준**:
  ```python
  # 화면을 3등분하여 좌측 판별
  if x < 213:  # 640 / 3
      # 좌회전 또는 좌측 처리
  ```
- **인정 패턴**:
  - `x < LEFT` 또는 `x < 213`
  - `x < 640 / 3`
  - "left", "왼쪽", "좌측" 키워드와 함께 x 좌표 사용
- **점수 부여**: 패턴 발견 시 1점

**2-2. 중앙 영역 판별 (1점)**
- **평가 기준**:
  ```python
  elif 213 <= x < 427:  # 640 * 2 / 3
      # 직진 처리
  ```
- **인정 패턴**:
  - 범위 체크 (213 <= x < 427)
  - "center", "middle", "중앙" 키워드 사용
  - `elif` 문으로 중간 영역 처리
- **점수 부여**: 패턴 발견 시 1점

**2-3. 우측 영역 판별 (1점)**
- **평가 기준**:
  ```python
  else:  # x >= 427
      # 우회전 또는 우측 처리
  ```
- **인정 패턴**:
  - `x > RIGHT` 또는 `x >= 427`
  - "right", "오른쪽", "우측" 키워드 사용
- **점수 부여**: 패턴 발견 시 1점

#### 왜 이렇게 평가하는가?
위치 추적은 자율주행의 핵심 기능입니다. 화면을 3등분하여 객체의 위치를 판별하는 것은 실제 자율주행에서 **차선 인식** 및 **장애물 회피**와 유사한 개념입니다. 각 영역을 독립적으로 평가하여 학생이 **조건 분기**를 정확히 이해하고 있는지 확인합니다.

### 3. 거리 판단 로직 (총 4점)

#### 평가 목적
표지판의 width 크기를 기반으로 거리를 판단하는 로직을 평가합니다. 이는 실제 컴퓨터 비전에서 사용되는 원리입니다.

#### 세부 항목

**3-1. 원거리 판별 (2점)**
- **평가 기준**:
  ```python
  # width가 작으면 멀리 있음
  if width < 90:
      print("원거리 - 전진하여 접근")
  ```
- **인정 패턴**:
  - `width < 90` 또는 `width < FAR`
  - "far", "멀", "원거리" 키워드 사용
  - "small", "작" 등 크기 표현
- **점수 부여**: 패턴 발견 시 2점

**3-2. 근거리 판별 (2점)**
- **평가 기준**:
  ```python
  # width가 크면 가까이 있음
  if width >= 120:
      print("근거리 - 주차 시작")
  ```
- **인정 패턴**:
  - `width >= 120` 또는 `width > CLOSE`
  - "near", "close", "가까", "근거리" 키워드
  - "large", "big", "크" 등 크기 표현
- **점수 부여**: 패턴 발견 시 2점

#### 왜 이렇게 평가하는가?
거리 판단은 **원근법(perspective)**의 기본 원리를 이해하고 있는지 확인합니다. 카메라 이미지에서 객체의 크기로 거리를 추정하는 것은 실제 자율주행 시스템에서 핵심적인 기능입니다. 원거리와 근거리를 각각 2점으로 배점하여 **양방향 판단 능력**을 평가합니다.

### 4. 표지판 처리 로직 (총 2점)

#### 평가 목적
stop과 danger 표지판을 감지하고 적절히 대응하는 로직을 평가합니다.

#### 세부 항목

**4-1. stop 표지판 처리 (1점)**
- **평가 기준**:
  ```python
  if sign == "stop":
      print("정지 표지판 인식!")
      # 기어모터 정지
      # 부저 3회
      break  # 또는 continue, return
  ```
- **인정 패턴**:
  - "stop", "정지", "중지", "멈춤" 키워드
  - `break`, `continue`, `return`, `exit` 제어문 사용
  - `if...stop` 조건문
- **점수 부여**: 패턴 발견 시 1점

**4-2. danger 표지판 처리 (1점)**
- **평가 기준**: stop과 동일한 패턴
- **인정 패턴**:
  - "danger", "위험", "충돌" 키워드
  - 제어문과 함께 사용
- **점수 부여**: 패턴 발견 시 1점

#### 왜 이렇게 평가하는가?
표지판 처리는 **안전 제어 로직**의 핵심입니다. stop과 danger를 감지하고 즉시 주행을 종료하는 것은 실제 자율주행에서 **긴급 정지(emergency stop)** 기능에 해당합니다. 각 표지판을 독립적으로 평가하여 **예외 상황 처리 능력**을 확인합니다.

### 5. 주행 제어 로직 (총 4점)

#### 평가 목적
차량의 기본적인 주행 제어(전진, 좌회전, 우회전, 후진/정지)를 구현했는지 평가합니다.

#### 세부 항목

**5-1. 전진 주행 로직 (1점)**
- **평가 기준**:
  ```python
  def go_forward():
      print("차량이 직진합니다")
      # 또는
  if direction == "up":
      print("전진")
  ```
- **인정 패턴**:
  - `go()`, `forward`, `move_forward`, "전진", "앞" 키워드
  - `speed = 양수` 설정
  - "motor", "drive", "straight" 키워드
- **점수 부여**: 패턴 발견 시 1점

**5-2. 좌회전 제어 로직 (1점)**
- **인정 패턴**:
  - `turn_left()`, "left", "왼쪽", "좌회전" 키워드
  - `steer...left` 또는 `rotate...left`
- **점수 부여**: 패턴 발견 시 1점

**5-3. 우회전 제어 로직 (1점)**
- **인정 패턴**: 좌회전과 대칭되는 패턴
- **점수 부여**: 패턴 발견 시 1점

**5-4. 후진/정지 제어 로직 (1점)**
- **인정 패턴**:
  - `back()`, `reverse()`, `stop()` 함수
  - "후진", "뒤", "정지", "halt" 키워드
  - `speed = 0` 또는 "brake"
- **점수 부여**: 패턴 발견 시 1점

#### 왜 이렇게 평가하는가?
주행 제어는 자율주행의 **최종 출력(actuator control)**에 해당합니다. 4가지 기본 동작을 모두 구현해야 완전한 주행 시뮬레이션이 가능합니다. 각 동작을 1점씩 배정하여 **균등한 중요도**를 부여합니다.

### 6. random 생성 후 조건 로직 연결 (1점)

#### 평가 목적
random으로 상황을 생성한 후, 이를 조건문을 통해 제어 로직에 연결했는지 평가합니다.

#### 평가 기준
```python
# 패턴 1: random 직후 if문
sign = random.choice(["stop", "danger", "o_sign"])
if sign == "stop":
    # 처리

# 패턴 2: 함수 분리
def generate_situation():
    return random.choice(...)

def handle_left():
    # 좌측 처리
```

#### 인정 조건
1. `random.` 사용 확인
2. random 호출 후 100자 이내에 `if` 문 존재
3. 또는 random을 사용하는 함수와 처리 함수가 분리되어 있음

#### 왜 이렇게 평가하는가?
이 항목은 **로직의 연결성**을 평가합니다. 단순히 random을 사용하는 것이 아니라, 생성된 랜덤 값을 실제 제어 로직에 연결하는 능력을 확인합니다. 이는 **데이터 흐름(data flow)** 이해도를 측정합니다.

### 7. 코드 품질 (총 3점)

#### 평가 목적
코드의 구조, 가독성, 안정성을 종합적으로 평가합니다.

#### 세부 항목

**7-1. 함수 분리 구조화 (1점)**

| 함수 개수 | 평가 | 점수 |
|-----------|------|------|
| 7개 이상 | 매우 우수 | 1점 |
| 5~6개 | 우수 | 1점 |
| 3~4개 | 양호 | 1점 |
| 2개 이하 | 미흡 | 0점 |

- **평가 기준**:
  ```python
  # 권장 함수 분리 예시
  def generate_random_rect()      # 랜덤 생성
  def detect_position(x)          # 위치 판별
  def calculate_distance(width)   # 거리 계산
  def handle_sign(sign_type)      # 표지판 처리
  def turn_left()                 # 좌회전
  def turn_right()                # 우회전
  def go_forward()                # 전진
  def stop_vehicle()              # 정지
  ```

- **왜 7개 이상인가?**
  - 자율주행 시뮬레이션의 주요 기능을 충분히 분리하려면 최소 7개 이상의 함수가 필요합니다.
  - **단일 책임 원칙(Single Responsibility Principle)**: 각 함수는 하나의 명확한 역할만 수행해야 합니다.
  - 7개 이상의 함수는 코드가 잘 구조화되어 있음을 의미합니다.

**7-2. 의미있는 변수명 사용 (1점)**
- **평가 기준**:
  - 3개 이상의 명확한 변수명 사용
  - 예: `position`, `distance`, `speed`, `angle`, `left`, `right`, `center`, `위치`, `거리`, `방향`
- **왜 중요한가?**
  - 코드의 **자기 문서화(self-documenting code)**
  - 다른 사람이 읽기 쉬운 코드
  - 유지보수성 향상

**7-3. 예외/에러 처리 (1점)**
- **평가 기준**:
  ```python
  # 패턴 1: try-except
  try:
      value = int(input())
  except ValueError:
      value = 0
  
  # 패턴 2: 조건 체크
  if value is None:
      value = default_value
  ```
- **왜 필요한가?**

- **설계 능력(design capability)** 보유를 입증

**3. 복잡도 관리**
- 2개 이상의 클래스 사용은 **시스템 설계 능력**을 보여줌

### 2. rect 랜덤 좌표 생성 검증 구현

#### 2-1. 헬퍼 함수: 범위 기반 검증

```python
def _has_random_range(
    text: str,
    name_tokens: Tuple[str, ...],      # 변수명 후보들
    start_tokens: Tuple[str, ...],     # 시작 범위 후보들
    end_tokens: Tuple[str, ...]        # 끝 범위 후보들
) -> bool:
    """
    특정 변수가 범위 내에서 랜덤 생성되는지 확인
    
    예시:
        x = random.randint(0, 640)
        y = random.randint(Y_MIN, Y_MAX)
    """
    for var in name_tokens:
        for start in start_tokens:
            for end in end_tokens:
                # 패턴: 변수명 = random.함수(시작범위, 끝범위)
                pattern = rf"{var}\s*=\s*random\.\w+\([^)]*{start}[^,)]*,[^)]*{end}"
                if re.search(pattern, text, re.IGNORECASE):
                    return True
    return False
```

**패턴 설명:**
- `{var}\s*=\s*`: 변수명 다음에 공백 허용하고 = 기호
- `random\.\w+\(`: random.randint 또는 random.randrange 등
- `[^)]*{start}[^,)]*,`: 시작값 찾기 (괄호 닫기 전까지)
- `[^)]*{end}`: 끝값 찾기

**패턴 분석:**
```python
# 패턴 1: x < 213 형태
r"(x|pos|position)\s*(?:<=|<)\s*(?:LEFT|21[023]|640\s*/\s*3|200|220)"

# 분해:
# (x|pos|position)     → x, pos, position 중 하나
# \s*                  → 공백 0개 이상
# (?:<=|<)            → <= 또는 < 연산자
# \s*                  → 공백 0개 이상
# (?:LEFT|21[023]|...) → LEFT 상수 또는 210~213 숫자 등

# 패턴 2: if문과 함께 키워드 사용
r"(?:left|왼쪽|좌측).*if.*(?:x|pos)"

# 분해:
# (?:left|왼쪽|좌측)  → 왼쪽 관련 키워드
# .*                  → 중간에 아무 문자
```

### 9. 점수 계산 전체 프로세스

```python
def calculate_score(student_result: StudentResult) -> int:
    """
    최종 점수 계산
    
    단계:
    1. 기본 점수 70점에서 시작
    2. 각 평가 항목 통과 시 점수 추가
    3. 보너스 점수 추가
    4. 감점 적용 (현재 0점)
    5. 핵심 요구사항 충족 시 90점 보장
    6. 최종 범위 조정 (70~100)
    """
    
    # 1단계: 기본 점수
    score = 70
    
    # 2단계: 평가 항목 점수 추가
    for detail in student_result.details:
        if detail.passed:
            score += detail.points
    
    # 3단계: 보너스 점수
    score += student_result.bonus
    
    # 4단계: 감점 (현재 0)
    score -= student_result.chatgpt_penalty
    score -= student_result.clone_penalty
    
    # 5단계: 핵심 요구사항 충족 시 90점 보장
    core_checks = [
        d for d in student_result.details
        if d.points in (POINT_RANDOM_EACH, POINT_POSITION_EACH, 
                        POINT_DISTANCE_EACH, POINT_CONTROL_EACH)
    ]
    if core_checks and all(d.passed for d in core_checks):
        score = max(score, 90)
    
    # 6단계: 최종 범위 조정
    score = max(70, min(100, score))
    
    return score
```

### 11. 정규표현식 패턴 레퍼런스

#### 기본 정규표현식 기호 설명

| 기호 | 의미 | 예시 |
|------|------|------|
| `.` | 임의의 한 문자 (줄바꿈 제외) | `a.c` → "abc", "a1c" 매칭 |
| `*` | 0회 이상 반복 | `ab*c` → "ac", "abc", "abbc" 매칭 |
| `+` | 1회 이상 반복 | `ab+c` → "abc", "abbc" 매칭 (ac는 불가) |
| `?` | 0회 또는 1회 | `ab?c` → "ac", "abc" 매칭 |
| `\s` | 공백 문자 (스페이스, 탭 등) | `a\sb` → "a b" 매칭 |
| `\w` | 단어 문자 (알파벳, 숫자, _) | `\w+` → "hello", "test123" 매칭 |
| `\d` | 숫자 | `\d+` → "123", "456" 매칭 |
| `[abc]` | a, b, c 중 하나 | `[abc]` → "a", "b", "c" 매칭 |
| `[0-9]` | 0부터 9까지 숫자 | `[0-9]+` → "123" 매칭 |
| `[^abc]` | a, b, c를 제외한 문자 | `[^0-9]` → 숫자가 아닌 문자 |
| `(a|b)` | a 또는 b | `(left|right)` → "left" 또는 "right" |
| `(?:...)` | 그룹화 (캡처 안 함) | `(?:abc)+` → "abc", "abcabc" |
| `^` | 문자열 시작 | `^def` → 줄 시작에 "def" |
| `$` | 문자열 끝 | `end$` → 줄 끝에 "end" |

#### 본 평가 시스템에서 자주 사용하는 패턴

**패턴 1: 변수 할당 감지**

```python
# 설명:
# (x|y|width)  → x, y, width 중 하나
# \s*          → 공백 0개 이상
# =            → 등호
# \s*          → 공백 0개 이상

# 매칭: "x = ", "y=", "width  =  "
```

**패턴 2: 함수 호출 감지**
```python
r"random\.\w+\("

# 설명:
# random       → "random" 문자열
# \.           → 점(.) 문자 (이스케이프 필요)
# \w+          → 단어 문자 1개 이상
# \(           → 여는 괄호 (이스케이프 필요)

# 매칭: "random.randint(", "random.choice(", "random.random("
```

**패턴 3: 조건문 감지**
```python
r"if.*(?:x|pos).*(?:<=|<)"

# 설명:
# if           → "if" 키워드
# .*           → 임의 문자 0개 이상
# (?:x|pos)    → x 또는 pos (캡처 안 함)
# .*           → 임의 문자 0개 이상
# (?:<=|<)     → <= 또는 <

# 매칭: "if x < 213", "if pos <= LEFT"
```

**패턴 4: 범위 내 매칭**
```python
r"[^\n]{0,200}"

# 설명:
# [^\n]        → 줄바꿈이 아닌 문자
# {0,200}      → 0~200개

# 용도: 같은 줄 또는 인접한 줄에서만 매칭
```

**패턴 5: 클래스 정의 감지**
```python
r"class\s+\w+"

# 설명:
# class        → "class" 키워드
# \s+          → 공백 1개 이상 (필수)
# \w+          → 단어 문자 1개 이상 (클래스명)

# 매칭: "class Vehicle", "class Sign", "class Simulator"
```

#### 플래그 설명

| 플래그 | 의미 | 사용 예시 |
|--------|------|-----------|
| `re.IGNORECASE` | 대소문자 구분 안 함 | LEFT와 left 모두 매칭 |
| `re.DOTALL` | `.`이 줄바꿈도 매칭 | 여러 줄에 걸친 패턴 |
| `re.MULTILINE` | `^`와 `$`가 각 줄에 적용 | 여러 줄 처리 |

#### 패턴 테스트 도구

```python
def test_pattern(pattern: str, test_cases: List[Tuple[str, bool]]) -> None:
    """
    정규표현식 패턴을 여러 테스트 케이스로 검증
    
    Args:
        pattern: 테스트할 정규표현식 패턴
        test_cases: [(테스트_문자열, 예상_매칭_여부), ...]
    """
    print(f"패턴 테스트: {pattern}")
    print("-" * 60)
    
    for text, expected in test_cases:
        match = re.search(pattern, text, re.IGNORECASE)
        result = bool(match)
        status = "✅ PASS" if result == expected else "❌ FAIL"
        
        print(f"{status} | 예상: {expected} | 실제: {result}")
        print(f"       | 텍스트: {text}")
        if match:
            print(f"       | 매칭: {match.group()}")
        print()

# 사용 예시
test_pattern(
    r"(x|pos)\s*(?:<=|<)\s*(?:213|640\s*/\s*3)",
    [
        ("if x < 213:", True),
        ("if x < 640 / 3:", True),
        ("if pos <= 213:", True),
        ("if x > 427:", False),
        ("x = 100", False),
    ]
)
```

```python
def analyze_item_pass_rate(csv_file: str) -> Dict[str, float]:
    """각 평가 항목의 통과율 계산"""
    import pandas as pd
    
    df = pd.read_csv(csv_file, encoding='utf-8-sig')

        pass_rates[column] = (passed / total * 100) if total > 0 else 0
    
    return pass_rates
```

## 부록: FAQ

### Q1. 왜 함수를 7개 이상 만들어야 하나요?
**A:** 자율주행 시뮬레이션의 주요 기능(랜덤 생성, 위치 판별, 거리 계산, 표지판 처리, 4가지 주행 동작)을 제대로 분리하면 자연스럽게 7개 이상의 함수가 필요합니다. 이는 **단일 책임 원칙**을 따르는 좋은 프로그래밍 습관입니다.

### Q2. 클래스를 사용하면 왜 더 높은 점수를 받나요?
**A:** 클래스 사용은 단순히 문법을 아는 것을 넘어, **시스템 설계 능력**을 보여줍니다. 특히 2개 이상의 클래스를 사용하면 객체 간 상호작용을 설계할 수 있어야 하므로, 이는 **중급 이상의 프로그래밍 능력**을 의미합니다.

### Q3. ChatGPT를 사용해도 감점이 없나요?
**A:** 현재 설정에서는 감점이 없습니다. 다만, ChatGPT 의심 흔적은 기록됩니다. 학습 도구로서의 AI 활용을 인정하되, **최종적으로 코드를 이해하고 제출**하는 것이 중요합니다.

### Q4. 복제 코드는 어떻게 검사하나요?
**A:** 코드의 해시 값을 비교하여 완전히 동일한 코드를 감지합니다. 다만 현재는 감점 없이 **복제 의심** 표시만 합니다.

### Q5. 최소 70점은 어떻게 보장되나요?
**A:** 최종 점수 계산 시 `max(70, 계산된_점수)`로 처리하여, 어떤 경우에도 70점 이하로 떨어지지 않습니다.

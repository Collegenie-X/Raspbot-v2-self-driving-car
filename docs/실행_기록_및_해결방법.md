# 실행 기록 및 해결 방법

## 📋 발견된 문제 및 해결

사용자가 Raspberry Pi에서 확인한 내용과 해결 방법을 정리한 문서입니다.

---

## 🔍 발견된 실행 중인 서비스

### 1. 포트 8888: Jupyter Lab

```bash
# 확인 명령어 실행
pi@yahboom:~ $ lsof -i :8888

# 출력 결과
COMMAND   PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
jupyter-l 880   pi    9u  IPv4  10473      0t0  TCP *:8888 (LISTEN)
```

**발견 사항:**
- **프로세스**: jupyter-lab
- **PID**: 880
- **사용자**: pi
- **역할**: Jupyter 노트북 서버 (포트 8888)

**해결 방법:**
```bash
# 프로세스 종료
kill 880

# 확인
lsof -i :8888
# 출력: 포트 8888에서 실행 중인 프로세스가 없습니다 ✅
```

## ✅ 해결 방법 요약

### 1단계: 현재 실행 중인 서비스 모두 종료

```bash
# Jupyter 종료 (포트 8888)
pkill -f "jupyter"

# yb-discover 종료 (포트 8000)
pkill -f "yb-discover"

# raspbot.pyc 종료
pkill -f "raspbot.pyc"

# 확인
lsof -i :8888
lsof -i :8000
ps aux | grep -E "jupyter|raspbot|yb-discover" | grep -v grep
```

---

### 2단계: 부팅 시 자동 시작 막기

#### 🔴 중요: systemctl status로 발견된 서비스

`sudo systemctl status` 출력에서 다음 서비스들이 발견되었습니다:

**A. jupyter.service (systemd 서비스)**
```bash
├─jupyter.service
│ └─6347 /usr/bin/python3 /home/pi/.local/bin/jupyter-lab
```

**B. raspbot.pyc (GUI 세션 자동 시작)**
```bash
├─1325 python3 /home/pi/project_demo/raspbot/raspbot.pyc
```

#### 해결 방법:

#### A. jupyter.service 비활성화 (systemd)

```bash
# 1. jupyter 서비스 중지
sudo systemctl stop jupyter.service

# 2. 부팅 시 자동 시작 비활성화
sudo systemctl disable jupyter.service

# 3. 확인
sudo systemctl status jupyter.service
# 출력: "disabled"로 표시되면 성공 ✅

# 4. 현재 프로세스도 종료
pkill -f "jupyter-lab"
```

#### B. raspbot.pyc 자동 시작 막기 (GUI 자동 시작)

raspbot.pyc는 session-1.scope에서 실행되므로 GUI 자동 시작입니다.

**방법 1: autostart 파일 확인 및 제거**
```bash
# 사용자 autostart 확인
ls -la ~/.config/autostart/

# raspbot 관련 파일 삭제
rm ~/.config/autostart/start_raspbot.desktop 2>/dev/null
rm ~/.config/autostart/raspbot*.desktop 2>/dev/null

# 전역 autostart 확인
ls -la /etc/xdg/autostart/

# 전역 autostart에서 삭제 (있다면)
sudo rm /etc/xdg/autostart/raspbot*.desktop 2>/dev/null
```

**방법 2: cron 확인**
```bash
# cron 작업 확인
crontab -l

# @reboot로 raspbot이 시작되는지 확인
# 있다면 편집하여 삭제
crontab -e
# @reboot ... raspbot ... 줄 삭제 또는 주석 처리
```

**방법 3: 시스템 전역 cron 확인**
```bash
# /etc/crontab 확인
sudo cat /etc/crontab | grep raspbot

# /etc/cron.d/ 확인
ls -la /etc/cron.d/ | grep raspbot
```

#### C. raspbot 서비스 비활성화 (있는 경우)

```bash
# raspbot 서비스 확인
sudo systemctl list-units --all | grep raspbot

# 발견되면 비활성화
sudo systemctl stop raspbot.service 2>/dev/null
sudo systemctl disable raspbot.service 2>/dev/null
```

**cron 확인:**
```bash
crontab -l

# jupyter가 @reboot로 시작하는지 확인
# 있다면:
crontab -e
# 해당 줄 삭제 또는 주석 처리 (맨 앞에 # 추가)
```

**autostart 확인:**
```bash
ls ~/.config/autostart/

# jupyter 관련 파일 삭제
rm ~/.config/autostart/jupyter*.desktop
```

#### D. yb-discover 자동 시작 막기

yb-discover는 일반적으로 raspbot.service에 포함되어 실행되므로, raspbot.service를 비활성화하면 함께 중지됩니다.

---

### 2-1단계: 빠른 실행 스크립트 (모두 한 번에)

```bash
#!/bin/bash
# 모든 자동 시작을 한 번에 비활성화하는 스크립트

echo "=== 1. systemd 서비스 비활성화 ==="
sudo systemctl stop jupyter.service 2>/dev/null
sudo systemctl disable jupyter.service 2>/dev/null
sudo systemctl stop raspbot.service 2>/dev/null
sudo systemctl disable raspbot.service 2>/dev/null

echo ""
echo "=== 2. 현재 실행 중인 프로세스 종료 ==="
pkill -f "jupyter-lab"
pkill -f "raspbot.pyc"
pkill -f "yb-discover.py"

echo ""
echo "=== 3. autostart 파일 제거 ==="
rm ~/.config/autostart/start_raspbot.desktop 2>/dev/null
rm ~/.config/autostart/raspbot*.desktop 2>/dev/null
rm ~/.config/autostart/jupyter*.desktop 2>/dev/null
sudo rm /etc/xdg/autostart/raspbot*.desktop 2>/dev/null
sudo rm /etc/xdg/autostart/jupyter*.desktop 2>/dev/null

echo ""
echo "=== 4. 확인 ==="
echo "--- jupyter.service 상태 ---"
sudo systemctl is-enabled jupyter.service 2>&1 || echo "비활성화됨 ✅"

echo ""
echo "--- 실행 중인 프로세스 ---"
ps aux | grep -E "jupyter|raspbot|yb-discover" | grep -v grep || echo "없음 ✅"

echo ""
echo "--- 포트 사용 확인 ---"
lsof -i :8888 2>/dev/null || echo "포트 8888: 사용 안 함 ✅"
lsof -i :8000 2>/dev/null || echo "포트 8000: 사용 안 함 ✅"

echo ""
echo "==================================="
echo "완료! 재부팅 후 완전히 적용됩니다."
echo "재부팅: sudo reboot"
echo "==================================="
```

**실행 방법:**
```bash
# 스크립트를 파일로 저장
nano ~/stop_autostart.sh
# (위 내용 붙여넣기)

# 실행 권한 부여
chmod +x ~/stop_autostart.sh

# 실행
./stop_autostart.sh
```

---

### 3단계: 재부팅 후 확인

```bash
# 재부팅
sudo reboot

# 재부팅 후 확인
lsof -i :8888

# 아무것도 실행되지 않으면 성공! ✅
```

## 🔧 개발 모드 vs 운영 모드

### 개발 모드 (권장)

**자동 시작 비활성화 → 필요할 때만 수동 실행**

```bash
# 1. 자동 시작 비활성화
sudo systemctl disable raspbot.service
sudo systemctl disable jupyter.service
crontab -e  # 관련 줄 삭제

# 2. 필요할 때만 수동 시작
sudo systemctl start raspbot.service
# 또는
jupyter lab

# 3. 작업 완료 후 중지
sudo systemctl stop raspbot.service
pkill -f "jupyter"
```

### 운영 모드 (데모/발표용)

**자동 시작 활성화 → 재부팅 후 자동으로 시작**

```bash
# systemd 방식
sudo systemctl enable raspbot.service
sudo systemctl start raspbot.service

# cron 방식
crontab -e
# 추가:
# @reboot sleep 10 && /bin/sh /home/pi/project_demo/raspbot/raspbot_start.sh
```

## 🆘 추가 문제 해결

### "포트가 이미 사용 중입니다" 오류

```bash
# 포트 사용 프로세스 확인
lsof -i :8888
lsof -i :8000

# PID 확인 후 종료
kill PID번호

# 강제 종료 (응답 없을 때)
kill -9 PID번호
```

### "Permission denied" 오류

```bash
# sudo 권한 추가
sudo lsof -i :8888
sudo kill PID번호
```

### 프로세스가 계속 재시작됨

```bash
# raspbot.service는 자동 재시작 설정됨
# 완전히 중지하려면:
sudo systemctl disable raspbot.service
sudo systemctl stop raspbot.service

# 서비스 파일 확인
cat /etc/systemd/system/raspbot.service
# Restart=on-failure 설정 때문
```

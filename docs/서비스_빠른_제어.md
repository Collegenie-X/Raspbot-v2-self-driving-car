# ⚡ 서비스 빠른 제어 가이드

Raspberry Pi에서 바로 사용할 수 있는 간단한 명령어 모음입니다.

---

## 🔴 1단계: 현재 실행 중인 서비스 찾기 및 종료

### 포트 8888 (Jupyter)

```bash
# 확인
lsof -i :8888

# 종료 (PID 확인 후)
kill PID번호

# 또는 이름으로 종료
pkill -f "jupyter"
```

### 포트 8000 (yb-discover)

```bash
# 확인
lsof -i :8000

# 종료 (PID 확인 후)
kill PID번호

# 또는 이름으로 종료
pkill -f "yb-discover"
```

### 모든 관련 프로세스 종료

```bash
pkill -f "jupyter"
pkill -f "yb-discover.py"
pkill -f "raspbot.pyc"
sudo systemctl stop raspbot.service
```

---

## 🛑 2단계: 부팅 시 자동 시작 막기

### systemd 서비스 비활성화

```bash
# raspbot 서비스 비활성화
sudo systemctl disable raspbot.service
sudo systemctl stop raspbot.service

# jupyter 서비스 비활성화
sudo systemctl disable jupyter.service
sudo systemctl stop jupyter.service
```

### cron 작업 제거

```bash
# 편집기 열기
crontab -e

# @reboot로 시작하는 줄 찾아서 삭제 또는 주석 처리
# 예: @reboot jupyter lab
# 주석: # @reboot jupyter lab

# 저장: Ctrl+X, Y, Enter
```

### autostart 파일 제거

```bash
# autostart 디렉토리 확인
ls ~/.config/autostart/

# 관련 파일 삭제
rm ~/.config/autostart/start_raspbot.desktop
rm ~/.config/autostart/jupyter*.desktop
```

---

## ✅ 3단계: 부팅 시 자동 시작 설정

### systemd 방식 (권장)

```bash
# 1. 서비스 파일 복사
sudo cp /home/pi/project_demo/raspbot/raspbot.service /etc/systemd/system/

# 2. 리로드 및 활성화
sudo systemctl daemon-reload
sudo systemctl enable raspbot.service
sudo systemctl start raspbot.service

# 3. 확인
sudo systemctl status raspbot.service
```

### cron 방식

```bash
# 편집
crontab -e

# 추가
@reboot sleep 10 && /bin/sh /home/pi/project_demo/raspbot/raspbot_start.sh

# 저장: Ctrl+X, Y, Enter
```

## 📊 현재 상태 확인

```bash
# 활성화된 서비스 확인
sudo systemctl list-unit-files --state=enabled

# cron 작업 확인
crontab -l

# 실행 중인 프로세스 확인
ps aux | grep -E "jupyter|raspbot|yb-discover"

# 포트 사용 확인
lsof -i :8888
lsof -i :8000
```

---

## 🎯 자주 사용하는 명령어

```bash
# 서비스 시작
sudo systemctl start raspbot.service

# 서비스 중지
sudo systemctl stop raspbot.service

# 서비스 상태
sudo systemctl status raspbot.service

# 로그 확인
sudo journalctl -u raspbot.service -f

# 프로세스 강제 종료
sudo kill -9 PID번호
```
